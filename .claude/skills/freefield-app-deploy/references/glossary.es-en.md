# Glossary / Glosario: the tablet app (plain language)

Use these when the user asks "¿qué es…?" / "what is…?". One or two sentences, then stop unless they ask for more. For Firebase, Hosting, Blaze, Firestore, deploy and the rest of the website's words, see the web glossary in `vendor/free-field/.claude/skills/freefield-deploy/references/glossary.es-en.md`.

| Term | Español | English |
|---|---|---|
| **APK** | El archivo de la app que se instala en una tablet Android (termina en `.apk`). Es lo que construimos y copiamos o instalamos. | The file of the app that gets installed on an Android tablet (ends in `.apk`). It is what we build and install. |
| **AAB** (App Bundle) | Otro formato del mismo programa (`.aab`), que solo sirve para subirlo a Google Play. No se instala directamente en una tablet. | Another packaging of the same program (`.aab`), only for uploading to Google Play. It cannot be installed on a tablet directly. |
| **Signing key** / llave de firma | La "firma" de tu empresa para esta app. La tablet solo acepta actualizaciones firmadas con la misma llave. Si se pierde, no se puede actualizar: hay que desinstalar y se borran los datos sin conexión. **Se guarda en el gestor de contraseñas.** | Your company's "signature" for this app. A tablet only accepts updates signed with the same key. If lost, updates are impossible: you must uninstall and lose the offline data. **Keep it in the password manager.** |
| **Keystore** | El archivo que contiene la llave de firma (aquí `signing/<id>.p12`), protegido por contraseñas que están en `signing.local.properties`. | The file that holds the signing key (here `signing/<id>.p12`), protected by passwords stored in `signing.local.properties`. |
| **Fingerprint** / huella (SHA-256) | Un código corto que identifica la llave de firma. Es público y se publica en el sitio web para vincularlo con la app. | A short code that identifies the signing key. It is public and is published on the website to link it with the app. |
| **Application id** / id de aplicación | El nombre técnico único de la app, p. ej. `com.empresa.field`. Se elige una vez y **no puede cambiar**: si cambia, es otra app. | The app's unique technical name, e.g. `com.company.field`. Chosen once and **can never change**: if it changes it is a different app. |
| **versionCode / versionName** | `versionName` es la versión que ve la gente (`1.2.0`). `versionCode` es un número entero que sube de a 1 en cada versión: la tablet solo acepta actualizar a un número mayor. | `versionName` is the version people see (`1.2.0`). `versionCode` is a whole number raised by 1 for each release: a tablet only updates to a higher number. |
| **App Links** | Cómo Android abre un enlace de tu sitio web directamente en la app. Requiere que el sitio publique `/.well-known/assetlinks.json`. Sin eso, el enlace del correo abre el navegador. | How Android opens a link of your website directly in the app. It needs the website to serve `/.well-known/assetlinks.json`. Without it, the e-mailed link opens the browser. |
| **assetlinks.json** | El archivo público del sitio web que dice "esta app, firmada con esta llave, puede abrir mis enlaces". | The public website file that says "this app, signed with this key, may open my links". |
| **Sideload** / instalar a mano | Instalar la app desde un archivo y no desde una tienda. Android pide permiso "instalar desde esta fuente" y puede mostrar una advertencia de Play Protect. | Installing the app from a file instead of a store. Android asks to allow "install from this source" and may show a Play Protect warning. |
| **adb** | Herramienta de línea de comandos para hablar con la tablet por cable USB (instalar la app, ver errores). Requiere activar "Depuración USB". | A command-line tool to talk to the tablet over a USB cable (install the app, read errors). Needs "USB debugging" on. |
| **USB debugging** / depuración USB | Un interruptor en Opciones de desarrollador que deja a un computador instalar apps por cable. Se activa tocando 7 veces "Número de compilación". | A switch in Developer options that lets a computer install apps over a cable. Turn it on by tapping "Build number" 7 times. |
| **MDM** (gestión de dispositivos) | La herramienta de TI para administrar tablets de la empresa: instalar y actualizar apps sin tocarlas. | The IT tool that manages company tablets: installs and updates apps without touching them. |
| **Play Protect** | La revisión de seguridad de Google en la tablet. Puede advertir que una app de fuera de la tienda es "desconocida"; se puede elegir "Instalar de todos modos". | Google's on-device security check. It may warn that an app from outside the store is "unknown"; you can choose "Install anyway". |
| **Toolchain** / herramientas de compilación | Java 21 y el SDK de Android: lo que hace falta para convertir el código en la app. Se instalan solo en tu carpeta de usuario. | Java 21 and the Android SDK: what is needed to turn the code into the app. Installed only in your user folder. |
| **Gradle** | La herramienta que realmente compila la app Android. La primera vez descarga mucho. | The tool that actually builds the Android app. It downloads a lot the first time. |
| **Submódulo** (`vendor/free-field`) | La copia del código del sitio web de FreeField dentro de este repositorio, de la que la app reutiliza piezas. Hay que traerla con `git submodule update --init`. | The copy of the FreeField website code inside this repository, from which the app reuses parts. Fetch it with `git submodule update --init`. |
| **Emulator** / emulador | Una tablet virtual en el computador, para probar sin aparato real. | A virtual tablet on the computer, to test without a real device. |
| **Offline building** / edificio sin conexión | Un edificio (modelo, planos, incidencias) descargado en la tablet para trabajar sin internet. | A building (model, plans, tasks) downloaded to the tablet to work without internet. |
| **Outbox** / cola de envío | Los cambios hechos sin conexión que esperan para subirse. La pestaña **Sync** los muestra. | Changes made offline that wait to be uploaded. The **Sync** tab shows them. |
