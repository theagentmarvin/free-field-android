## Files copied into the app at build time

`apps/mobile/scripts/prepare-assets.mjs` copies the pdf.js runtime files from `pdfjs-dist` into the app bundle: `standard_fonts` (Foxit fonts, see `LICENSE_FOXIT`, and Liberation fonts under the SIL Open Font Licence 1.1, see `LICENSE_LIBERATION`), `cmaps` (Apache-2.0) and `wasm` (image decoders shipped with pdf.js, each with its own `LICENSE_*` file). Their licence files travel with them.

## Android build dependencies

The Android project (Gradle) pulls AndroidX and Google Play services libraries from Maven repositories under the Apache-2.0 licence.

## The FreeField web code

The `vendor/free-field` git submodule is the public FreeField web repository ([free-field-app](https://github.com/theagentmarvin/free-field-app), MIT). Its own `THIRD_PARTY_NOTICES.md` lists what it adds.

## Demo data

`apps/mobile/demo-seed/` holds a small generated demo data set: a `.frag` fragment file converted from the sample structural model of the FreeField web repository, and a floor-plan PDF generated by `apps/mobile/scripts/build-demo-seed.mjs`. Both are provided for demonstration and tests under the repository's MIT licence.
